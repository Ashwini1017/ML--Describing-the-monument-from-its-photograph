About Monument Vision

A classical Machine Learning system for heritage recognition

🎓

Academic Project

Built as a Final Year ML Project using purely classical machine learning — no deep learning, no neural networks.

🔬

Feature Extraction

Combines HOG (shape), HSV Color Histograms (color), LBP (texture), and ORB keypoint statistics into a unified feature vector.

🤖

ML Algorithms

Trains SVM (RBF), Random Forest, KNN, Decision Tree, and Naive Bayes. The best-performing model is auto-selected.

🏛

24 Monuments

Recognizes 24 famous Indian monuments including Taj Mahal, India Gate, Qutub Minar, Charminar, Golden Temple, and more.
